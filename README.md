# Project Title (Update)

Travel Planner

Add a description of your project here.

The Travel Planner app is a mobile application designed to help users organize and manage their trips efficiently. The app allows users to create and manage a travel checklist for packing and preparation. Users can add items, check them off when completed, uncheck them if needed, and items automatically disappear after remaining checked for one minute. The goal of the app is to make travel preparation simple, organized, and easy to manage from a mobile device.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Review the project requirements.
2. Build the screen layout in MIT App Inventor.
3. Build functions/functionality using blocks (add items, toggle check/uncheck, timer removal).
4. Implement memory using lists (and TinyDB if persistence is added).
5. Style and improve aesthetics of the app.
6. Test using MIT AI2 Companion or emulator.

Instructions for using the software:

1. Open the Travel Planner app.
2. Type a travel item into the text box.
3. Press the Add Item button to add it to the checklist.
4. Tap an item to check it off.
5. Tap again to uncheck it.
6. If an item remains checked for one minute, it will automatically be removed.
